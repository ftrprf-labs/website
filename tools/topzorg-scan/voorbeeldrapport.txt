TOELICHTING BIJ DIT VOORBEELD

Dit rapport is opgewekt door de scanner zelf, tegen de lokale nabootsing van de patiëntroute
(npm test, variant groen). Het laat zien welke uitvoer je krijgt bij een gezonde online route.

Het is uitdrukkelijk geen meting van de echte vestiging. De omgeving waarin deze PoC gebouwd is,
heeft geen netwerktoegang tot topzorggroep.nl, dus een live meting moet gedraaid worden vanaf een
werkplek met gewone internettoegang:

    cd tools/topzorg-scan
    npm ci && npx playwright install chromium
    npm run scan

De adressen in dit voorbeeld verwijzen daarom naar 127.0.0.1 en niet naar de productiesite.
